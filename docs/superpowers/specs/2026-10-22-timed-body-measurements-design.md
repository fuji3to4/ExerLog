# 体の数値を時刻付きで記録する（項目は一覧で拡張可能に）設計

日付: 2026-10-22
状態: 承認済み

## 背景と目的

体調（からだ・こころ）は、時刻付きで何件でも記録できるようになった（2026-10-20 の設計）。一方、身長・体重・体脂肪率は、まだ「1日1件」の作りのままである。

ユーザーは、気になったときに測った値を、朝・夜・運動の前後などの時刻付きで残したい。

このリポジトリは、運動管理の土台を MIT ライセンスで公開する位置づけにある。ユーザーは、このリポジトリを**コピーして**専門用途の別リポジトリを作る予定である。想定している用途は、リンパ浮腫のセルフケア手帳（`docs/memo/selfcare_6.pdf`）にあるような、腕・脚の左右の周径などを記録するものだ。

- コピー先では、まず**項目を足すだけ**で使いたい。
- そのあと、左右の比較や前回との差などの独自の画面を作っていくかもしれない。

そこで、このリポジトリでは一般的な項目（身長・体重・体脂肪率）だけを扱う。そのうえで、**項目を「一覧（設定）」として1か所にまとめ**、入力・表示・グラフ・同期・CSV がその一覧を読んで動くようにしておく。

## ゴール

1. 身長・体重・体脂肪率を、時刻付きで1日に何件でも記録できる。1回の記録では、測った項目だけを入力すればよい。
2. 体調と体の数値は、**1つの入口「＋ 記録する」**から記録する。開いた画面の中で「体調」と「体の数値」を切り替えられる（モックアップ「B案（改）」）。
3. 体の数値の記録は、タイムラインに体調と同じく時刻順で並ぶ。あとから修正・削除できる。
4. 測る項目は、1か所の項目一覧で定義する。コピー先ではそこに項目を足すだけで、次のすべてに新しい項目が出る。
   - 入力欄
   - タイムラインの表示
   - グラフの選択肢
   - スプレッドシートの列
   - CSV の列
5. BMI は今と同じく、体重を入れたときにその場で表示し、グラフでも見られる。

## ゴールではないもの

- 周径（左右）などの専門的な項目、左右の比較、前回との差の表示。これらはコピー先で作る。
- 項目をアプリの画面から追加・編集する機能。項目はコードの一覧で定義する。
- セルフケア（チェックリスト）の作りを変えること。
- 既存データの移行。前回と同じく作り直してよい（ベータ版）。

## 避けたいこと

- 体重だけを記録したいのに、体調の点数の入力を求められる。
- 開いた画面が目的と違い、閉じて開き直さなければならない。
- 測っていない項目まで、前回の値で新しく記録されてしまう。
- コピー先で項目を1つ足しただけで、同期によってスプレッドシートの既存の記録が消える。
- 項目を足すために、画面のあちこちを書き換えなければならない。

## 決まったこと（ユーザーの判断）

- **専門用途の扱い**：専門用途はリポジトリをコピーして作る。このリポジトリでは一般的な項目だけを扱い、項目は一覧で拡張できるようにする。
- **入口は1つ**：「＋ 記録する」を押すと記録画面が開く。画面上部に「体調」「体の数値」の切り替えが常に見えており、画面の中で切り替えられる。
  - これまでの「＋ 体調を記録」は、この入口に置き換える。「動画を選ぶ」はそのまま残す。
  - 理由：入口が最初から見えていること、開いたあとで種類を変えられること、将来、種類を増やしやすいこと。
- **体の数値の記録では、体調の点数を求めない**（体調と体の数値は別々の記録）。
- **前回の値の扱い**：入力欄に前回の値を**薄く表示**するだけにする。入力しなかった項目は保存しない。BMI は、身長を入力しなくても前回の身長で計算する。

## 私（Claude）の判断で決めたこと

ユーザーが変更できる。

### 項目一覧

- 項目は1つのファイル（例 `src/features/measurements/measurement-items.ts`）の配列で定義する。各項目が持つものは次のとおり。
  - `id`：保存とスプレッドシートの列名に使う。変えないこと。
  - 表示名の i18n キー
  - 単位（例 `kg`、`cm`、`%`）
  - 小数の桁数
  - 入力の最小値・最大値
  - グラフに出すかどうか
- 初期の項目は、身長（cm、1桁）、体重（kg、1桁）、体脂肪率（%、1桁）の3つ。
- BMI は項目ではなく、体重と身長から計算する派生値として扱う。
- 表示の順番は、配列の順番どおりにする。
- 一覧から外した項目の値が保存済みの記録に残っていても、エラーにせず、表示もしない。データは消さない。

### 記録の形

- 体の数値の記録は1件ごとに次を持つ。
  - id
  - 日付
  - 記録時刻
  - 値（項目 id → 数値の対応。測った項目だけを入れる）
  - メモ
  - 更新時刻
- 1件の中に値が1つもない記録は保存できない。保存ボタンを押せない状態にする。
- 削除時は、他の記録と同じく削除記録（tombstone）を残す。

### 記録画面

- 開いたときに表示する種類は、前回使った種類にする（この端末ごとに覚える）。
- 時刻と保存の動きは体調と同じにする。
  - 時刻は自動で入り、あとから直せる。
  - 保存すると「✓ 保存しました」が出て、新しい行が光る。
- 「体調」から「体の数値」に切り替えても、入力途中の内容は保存しない限り残らなくてよい。両方を一度に保存する機能は作らない。
- 前回の値は、その記録時刻より前に記録された値のうち、その項目を含む一番新しいものを使う。
- BMI の表示は今と同じで、数値だけを小数1桁で出す。身長が一度も記録されていなければ「身長を記録するとBMIが出ます」と出す。

### タイムライン

- 1行で表示する。例「07:12 📏 体重 60.2kg・体脂肪率 22.0%」。項目は一覧の順番で並べる。
- 体の数値の記録にも、体調と同じ規則で「朝」「動画前」「動画後」「夜」のラベルを付ける。ユーザーが「運動の前後に測る」と言っているため。
- 行を押すと記録画面が編集の状態で開き、修正・削除ができる。編集のときは種類の切り替えを出さない。

### ほかの画面

- **体調の画面（/self-care）**
  - 今ある「体調」のカード（＋ 体調を記録）と「体の数値」のカード（入力欄＋保存）を、1枚のカードにまとめる。
  - そのカードには「＋ 記録する」ボタンを1つだけ置き、「今日」画面と同じ記録画面を開く。開いたときの種類は前回使ったもの。
  - ボタンの下に、各項目の最新の値と測った日時、BMI を表示する。
  - セルフケアのチェックリストは今のまま残す。
- **履歴**
  - 日別表示の「体の数値」の欄はなくし、タイムラインに一本化する。
  - カレンダーでは、体の数値だけを記録した日にも小さな点を付ける。
- **グラフ**
  - 項目一覧のうち、グラフに出す項目を選択肢にする。
  - **記録した点をすべて描く（ユーザー判断）。** 日ごとの平均にはしない。
    - 横軸は日付ではなく時刻（記録時刻）で並べる。同じ日に3回測れば、その日の中に3点が並ぶ。
    - 目盛りは今と同じく「月/日」の表示でよい。点に触れたときの表示（ツールチップ）には時刻（例「10/22 07:12」）も出す。
  - **体調（からだ・こころ）のグラフも同じく全点表示にする。** 前回の設計の「日ごとの平均」を置き換える。
  - BMI は、体重を含む記録ごとに、その記録時刻以前で一番新しい身長を使って計算し、1点ずつ描く。

### 古いデータと古いタブ

- 前回と同じ「作り直してよい」の方針に従う。
  - 手元の `dailyMetrics` テーブルは、新しいスキーマの版で削除する。
  - 体の数値の記録は新しいテーブルに持つ。
- スプレッドシートには新しい名前のタブ（例 `Measurements`）を使う。
  - 古い `DailyMetrics` タブは読まず、書かず、消しもしない（放置）。
  - `table: "DailyMetrics"` の削除記録も、新しい表には使わない。

### シートの列の扱い

- 体の数値のタブを有効とみなす条件は、「固定の列（id、日付、記録時刻、メモ、更新時刻）をすべて見出しに含むこと」とする。
  - 1つでも欠けていれば、今の同期と同じく、そのタブを空として扱い、書き直す。
  - 条件を満たしていれば、見出しの名前で列を対応させる。
- 一覧にない列は、数値として読めるセルだけを記録の値として残す。数値でない文字は捨てる（手入力のごみ対策）。
- アプリで記録を修正するとき、画面に出ていない値（一覧にない項目）は消さずにそのまま残す。
- グラフやツールチップの小数の桁数は、各項目の設定に従う（初期の3項目はどれも1桁）。

### 同期と書き出し

- **スプレッドシート同期**：体の数値の表のタブは、固定の列（id、日付、記録時刻、メモ、更新時刻）の後ろに、項目一覧の id を列として並べる。
  - 今の同期は、見出しが一致しないタブを空として扱う。この表だけは、**見出しの名前で列を対応させる**。項目が増えたり並びが変わったりしても、既存の値を保つためである。
  - シートにあって一覧にない列の値は、記録の値として読み込み、そのまま書き戻す。消さない。
- **CSV**：同じく、固定の列の後ろに項目一覧の順で列を並べる。
- **全削除**：設定の「記録をすべて削除」の対象に、体の数値の記録を含める。

## builder に任せること

- 記録を保存するテーブルの設計と、スキーマの版の上げ方（作り直し可）。
- 項目一覧の型の細部と、i18n キーの命名。
- 記録画面のコンポーネントの分け方。今の `WellnessEntryDialog` を広げるか、新しいダイアログで包むか。
- 見出しの名前で列を対応させる処理の作り方。
- グラフ・CSV の内部の作り。
- テスト。少なくとも次は自動テストにする。
  - 項目一覧に1件足すと、入力・表示・同期の列・CSV の列に出ること。
  - シートの列が増減しても値が消えないこと。
  - 前回の値が入力欄に薄く表示されるだけで、保存されないこと。
