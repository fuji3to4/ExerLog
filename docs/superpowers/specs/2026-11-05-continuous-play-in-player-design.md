# 動画プレイヤー画面の連続再生・ループ・自動チェック 設計（v2）

日付: 2026-11-05
置き換え: `2026-11-05-my-list-continuous-play-design.md`（今日の画面の中で再生する案 C）。作ってみたら、ユーザーの考えていた使い方と違った。

## 意図と背景

運動するとき、リストの動画を 1 本ずつ開いて ▶ を押すのが面倒。スマホは床や机に置いて少し離れたところから見ている。

今のアプリでは、サムネイルや題名を押すと動画プレイヤー画面（`/exercises?exerciseId=…`、`ExerciseDetailScreen`）が開き、そこで ▶ を押して見る。
ユーザーの考えていた形は次のとおり。

- **このプレイヤー画面に「連続再生モード」がある。**
- オンにしておけば、開いた元のリストが順番に流れ続ける。
- 今日の画面からもライブラリからも同じように使える。

## ゴール

- プレイヤー画面に「連続再生」の切り替えを置く。オンのとき:
  - 画面を開いた瞬間に再生が始まる（▶ を押さなくていい）。
  - 動画が終わると、開いた元のリストの次の動画へ自動で進む。
  - ⏮ / ⏭ で 1 本戻る・飛ばす。
  - 🔁 ループ: オンなら最後のあと先頭に戻る。オフなら最後で止まる。
  - ✓ 自動チェック: オンなら、最後まで再生された動画に記録（`result: "did"`）を 1 件付ける。ループで 2 周すれば 2 件付く。
  - 「次に流れる」動画の一覧を出す。タップするとその動画に飛ぶ。
- 連続再生・ループ・自動チェックの 3 つとも、前回の設定を覚えておく（この端末の中だけ）。

## 流れるリスト（どこから開いたか）

プレイヤー画面を開いた元の画面で**見えているリストを、見えている順に**流す。始まりは押した動画。

| 開いた場所 | 流れるリスト |
|---|---|
| ライブラリ | 今表示されている並び。選んでいるマイリスト（なければ「すべて」）に、検索・絞り込み・並び替えをかけた結果。 |
| 今日の画面でマイリストを選んでいるとき | そのマイリスト（表示順） |
| 今日のおすすめ | そのとき表示されている 3 本（一時的なリスト。保存しない） |
| リストがわからない（リンクを直接開いた、再読み込みでリストが消えた等） | その 1 本だけ。ループがオンならその 1 本をくり返す |

絞り込み専用の仕組みは作らない（ユーザー:「さすがにそんな使い方はしない」）。「見えているまま」のルールに含まれるだけ。

## 画面（案 B、ユーザーが選んだもの）

上から順に:

1. 「← 戻る」の行。右側に「連続再生」の切り替え。
2. 連続再生がオンのときだけ、小さく 1 行。
   - リストの名前と位置（例「朝 · 2/5」。おすすめなら「今日のおすすめ · 1/3」、ライブラリの「すべて」なら「すべて · 7/38」など）
   - 🔁 ループ と ✓ 自動チェック の切り替え
3. 動画（今の画面と同じ場所・大きさ）。
4. 連続再生がオンのときだけ、動画のすぐ下に大きめの ⏮ ⏭。離れていても押しやすい大きさにする。
5. 題名・メタ・記録ボタン・マイリスト・説明。今の画面のまま。**流れている動画に合わせて切り替わる**。手動の記録も、今流れている動画に付く。
6. 連続再生がオンのときだけ、いちばん下に「次に流れる」一覧（サムネイル＋題名）。

連続再生がオフのときは、2・4・6 を出さず、今の画面とまったく同じ動きにする。▶ を押すと 1 本だけ再生し、start/end 付き動画は区間をくり返す。

見た目は既存のスタイルに合わせる。薄い色の丸いボタン（36px 前後）を使い、濃いベタ塗りは使わない。メニューはその場に出すドロップダウンにし、下から出るシートは使わない。

## 決まっている振る舞い（ユーザーと合意済み）

- 自動チェックが付くのは、**最後まで再生された動画だけ**。⏭ や一覧タップで飛ばした動画、途中で止めた動画、画面を離れた動画には付けない。「一部できた」の自動判定はしない。
- 自動チェックの記録は、手動の記録と同じ日付に付く。過去の日から開いた場合（`?date=`）はその日になる。
- 連続再生がオンなら、プレイヤー画面を開いた瞬間に再生を始める。
- 動画が切り替わっても、YouTube プレイヤーは 1 つのまま `loadVideoById` で中身を差し替える。iframe を作り直すとスマホで自動再生が止められることがあるため。
- 再生が始まった動画ごとに「見た」記録（`recordWatchEvent`）を付ける。今の ▶ と同じ扱い。
- **連続再生中は画面を消さない。** 連続再生がオンで再生中のあいだは Screen Wake Lock を取る。停止したとき、画面を離れたとき、連続再生をオフにしたときは手放す。タブが隠れてから戻ったら取り直す。対応していないブラウザでは何もしない（ユーザー:「そうしたい」）。
- 同じ再生中に手動で記録した動画は、最後まで流れても自動チェックの記録を足さない。同じ 1 回の運動に記録が 2 件付かないようにするため（**私の判断**）。手動の結果が「一部できた」でも同じ扱い。
- プレイヤー画面を開いたまま連続再生を切り替えた場合（**私の判断**）:
  - オフ → オン: 今流れている動画を止めずに、そこから連続再生を続ける。何も流れていなければ、その場で再生を始める。
  - オン → オフ: 今の動画は最後まで流れて、そこで止まる。次へは進まない。
  - そのため、オフのときも同じ API プレイヤーを使ってよい。ただし、オフで ▶ から 1 本だけ再生した場合は、start/end 付き動画の区間くり返しを今と同じに保つ。
- タブが裏に回ったり画面がロックされたりしても、再生が続く限りは連続再生も自動チェックもそのまま続ける。画面を伏せて音だけで運動していても、運動はしているため（**私の判断**）。

## 非ゴール

- 今日の画面の中での再生（v2 で取り除く。後述）。
- 1 本の動画のくり返しを独立した機能として作ること。既存の区間ループは連続再生オフのときにそのまま残す。
- リストを保存したり共有したりすること。おすすめ 3 本は一時的なリストで、保存しない。

## アンチゴール

- 自動チェックがオフなのに記録が付く。飛ばした・止めた動画に記録が付く。手動の記録と自動の記録が二重に付く。
- 記録漏れの注意や再生を促す通知を出す（ユーザー方針: 記録はゆるく）。
- 連続再生がオフのときに、今のプレイヤー画面の動きが変わる。

## 既存の作業（ブランチ `feat/my-list-continuous-play`）の扱い

v1 の実装は `main` に入れていない。v2 はこのブランチの上で作り直す。

- **流用するもの**:
  - `getYouTubeClip`（`src/lib/video/youtube.ts`）
  - `playlist-queue.ts`（`playId` が通算で増え続ける reducer）
  - `playlist-settings-store.ts`（設定を保存し、画面のコピー間で同期する。ここに「連続再生オン/オフ」を足す）
  - `loadYouTubeIframeApi`
  - `PlaylistPlayer`。PLAYING を見たあとの ENDED だけを数え、`playId` 付きで通知する
  - `usePlaylist` の考え方。`handleEnded(playId)` で二重記録しない、自動チェックの値は終わった瞬間の設定を読む
- **取り除くもの**: 今日の画面に組み込んだ部分。`PlaylistControls`、`PlaylistSlot`、`PlaylistStage`、`today-screen.tsx` の配線とテスト、`VideoCard` / `RecommendedExerciseCard` の `media` / `onActivate` props、関連する CSS と文言。カードを押したら今までどおりプレイヤー画面へ移る。

## 作る人の判断に任せる部分

- 元のリストをプレイヤー画面に渡す方法。
  - 候補: カードを押したときに、リストの id 列・名前・種類を sessionStorage に書き、プレイヤー画面で読む。開いた `exerciseId` がそのリストに含まれていなければ「リストがわからない」扱いにする。
  - URL に id 列を全部載せるのは長くなるので避ける。
- 次の動画へ進んだときに URL（`?exerciseId=`）を書き換えるかどうか。書き換えるなら `history.replaceState` にして、戻る履歴を増やさない（**私の判断**）。
- 連続再生中に、元のリストから動画が消えたり変わったりした場合の扱い。止めるか、id で追いかけるか。落ちなければよい。
- 「次に流れる」一覧に何本出すか（全部か、数本＋「ほか n 本」か）。
- 自動チェックで記録したときのお祝い表示（`celebrate`）。出すなら、動画を隠したり再生を止めたりしないこと（**私の判断**）。
- 自動記録に失敗したら、既存の `log_save_error` を出して再生は続ける（**私の判断**）。
- 埋め込めない動画（YouTube 以外）は、連続再生では飛ばして次へ進む（**私の判断**）。開いた動画そのものが埋め込めないときは、今の画面と同じ「動画を見る」リンクを出し、自動では進まない。
- 連続再生がオンのときの初回自動再生がブラウザに止められたら、今と同じ ▶ を表示する。そこから押せば続きは連続で流れる（**私の判断**）。
