# 腕・脚の周径を左右で記録し、グラフで比べる 設計

日付: 2026-10-23
状態: 承認済み

## 背景と目的

このリポジトリ（Lymly）は、運動管理アプリ ExerLog をコピーして作る、リンパ浮腫のセルフケア向けの版である。
参考資料は、ナック商会の「セルフケア手帳」第6版（`docs/memo/selfcare_6.pdf`）。

手帳で一番ページ数が多いのは「Calendar Check」である。そこには、腕または脚の周径を左右それぞれ5か所書く欄と、「前回との差」を書く欄がある。
手書きでは、引き算や見比べが面倒になる。また、紙面の都合で記録できる回数にも限りがある。

ユーザーによれば、評価の基準になるのは次の2つである。

- **前回との差**
- **左右差**

乳がんなどの手術でリンパ節を切除した後遺症として、片側がむくむため、左右差が出やすい。
また、「むくんできた」と思ったとき、運動の後、朝と晩など、気になったときに何度でも記録したい。

ExerLog の 2026-10-22 の設計（`2026-10-22-timed-body-measurements-design.md`）で、体の数値は次のようになった。

- 時刻付きで、1日に何件でも記録できる。
- 項目は一覧（`src/features/measurements/measurement-items.ts`）に足すだけで、入力・表示・グラフ・同期・CSV に出る。

その設計には「周径（左右）、左右の比較、前回との差はコピー先で作る」と書かれている。今回がその作業にあたる。

## ゴール

1. 腕・脚の周径を、左右それぞれ5部位、時刻付きで何件でも記録できる。1回の記録では、測った欄だけを入力すればよい。
2. 記録画面の中で「腕｜脚」を切り替えられ、選んだ側の5部位だけが表示される。
3. 履歴のグラフで周径を選び、1つの部位について左右を色分けした2本の線で推移を見られる。
4. グラフの点に触れると、その時点の値、前回との差、左右差がわかる。
5. 測定位置の説明（ヘルプ）を、記録画面から開いて見られる。

## ゴールではないもの

- 手術前の値（基準値）を登録して比べること。
- 患側を設定して、色や警告を変えること。
- 蜂窩織炎の履歴、弾性着衣の購入履歴、食事やカロリーの記録（手帳にはあるが、今回は扱わない）。
- 体重グラフの「±5kg・±10kg」の目盛りや、標準体重の表示。
- 5部位を一覧で見比べる小さいグラフ（モックアップの C 案）。
- 最新の値を常に表示するカード（モックアップの B 案）。

## 避けたいこと

- 腕だけの人に脚の欄まで並び、腕から脚まで全部が羅列される画面。
- 測っていない欄が、前回の値で記録されてしまうこと。
- 記録の途中で「腕｜脚」を切り替えたら、入力済みの値が消えること。
- 周径の項目を足したことで、同期によってスプレッドシートの既存の記録が消えること。
- 手帳のイラストや写真を、そのままアプリに取り込むこと（著作物のため）。

## 決まったこと（ユーザーの判断）

- **対象は周径だけ。** 蜂窩織炎・弾性着衣・食事は、今回は対象外とする。
- **記録の回数に制限はない。** 今の「体の数値」と同じく、時刻付きで何件でも記録できる。
- **評価は「前回との差」と「左右差」。**
- **腕／脚は選べる形にする。** 全部位を並べることはしない。選ぶ場所は、**記録画面の中の切り替え（B 案）**とする。設定で一度だけ選ぶ形（A 案）にはしない。
- **グラフは A 案。** 部位を1つ選び、左右を色分けした2本の線を描く。差は、点に触れたときに出る吹き出しで見せる。
- **手術前の値との比較は、今回は外す。**
- **測定位置のヘルプを付ける。** 手帳4ページの「測定方法」にあたる説明を、ポップアップで見られるようにする。

## 私（Claude）の判断で決めたこと

ユーザーが変更できる。

### 測る部位

手帳の「Calendar Check」の欄にそろえる。腕・脚ともに5部位とし、それぞれ左右を測る。部位の名前は、手帳4ページの測定方法に合わせる。

| 順 | 腕 | 脚 |
| --- | --- | --- |
| 1 | 手のひら | 足の甲 |
| 2 | 手首 | 足首 |
| 3 | 肘下5cm | 膝下5cm（ふくらはぎ） |
| 4 | 肘上10cm | 膝上10cm |
| 5 | 腋窩 | 脚のつけ根 |

- 単位は cm、小数1桁。入力できる範囲は 5〜150 cm とする（脚のつけ根も入る幅）。
- 項目は、今の項目一覧に20件（腕10・脚10）を足して定義する。
  - 体重などと同じ「1か所の一覧」を正とする。
  - 各項目に、どの部位（腕／脚）の、どの位置の、どちら側（左／右）かを持たせ、画面はそれを読んで並べる。
  - 一覧の型を広げる方法は、作る人に任せる。
- 周径の項目は、今の「グラフの項目を1つ選ぶ」一覧には出さない。周径用の表示（下記）から見る。

### 記録画面

- 「＋ 記録する」→「体の数値」の中で、体重・体脂肪率・身長の欄の下に「周径（cm）」の欄を置く。
- 見出しの横に、「腕｜脚」の切り替えと「？」（ヘルプ）ボタンを置く。
- 開いたときは、この端末で前回使ったほう（腕／脚）を選んだ状態にする。初めて開くときは「腕」とする。
- 欄は「左｜右」の2列×5部位で、手帳と同じ並びにする。左右の色は、グラフと同じ色を見出しに付ける。
- 前回の値の扱いは、今の体の数値と同じにする。
  - 前回の値は、欄に薄く表示するだけにする。
  - 入力しなかった欄は保存しない。
  - 1欄だけの記録も、片側だけの記録もできる。
- 「腕｜脚」を切り替えても、入力途中の値は残す。保存すると、腕と脚の値をまとめて1件の記録にする。
- 修正のときは、その記録に値がある側（腕または脚）を選んだ状態で開く。腕と脚の両方に値があるときは、腕を選んだ状態で開く。
- 周径だけ、体重だけ、両方の組み合わせ、のどれでも1件として保存できる。
- 表示していない側（たとえば脚を表示中の腕の欄）に、範囲外などの正しくない値が残っている場合は、保存できない状態にする。切り替えのその側に印（例「腕 ⚠」）を付けて、どこを直せばよいかわかるようにする。
- 「前回使った腕／脚」は、記録画面とグラフで同じ1つの値を共有する。どちらかで切り替えると、もう一方も次に開いたときにその側で開く。

### 測定位置のヘルプ

- 記録画面の「？」を押すと、ポップアップ（ダイアログ）が開く。そのとき選んでいる側（腕／脚）の5部位について、測る位置を短い文で示す。
- 手帳4ページの内容をもとに、アプリ用に書き直した文を使う。
  - 共通：測る時刻は、起床後か就寝前など、ある程度そろえる。
  - 手のひら：こぶしを握ったときに4つ並ぶ骨の出っ張りを通る周り。
  - 足の甲：親指の骨の根元で土踏まずのアーチが始まる点から、小指側の出っ張りの手前までを通る周り。
  - 肘下5cm・肘上10cm・膝下5cm・膝上10cm：肘や膝のお皿を基準に、そこから5cm下、10cm上の周り。
  - 腋窩・脚のつけ根：手帳の図には説明がない。そのため「わきの下」「脚のつけ根」を一周する位置と、短く書くだけにする。
  - 弾性着衣を選ぶときは、測る位置がメーカーごとに違うことも添える（手帳3ページの注記）。
- 図は、手帳のイラストを使わない。腕・脚の簡単な線画に、5か所の番号を付けた図を、アプリ用に新しく作る（インラインSVGなど）。
- 文は日本語と英語の両方を用意する。
- 医療的な判断は書かない。測り方の説明にとどめる。

### タイムライン

- 1行で表示する。周径は値を並べず、件数だけを出す。
  - 例：「07:05 📏 体重 60.2kg・腕の周径 10か所」
  - 例：「21:30 📏 脚の周径 4か所」
  - 腕と脚の両方がある記録の例：「07:05 📏 腕の周径 10か所・脚の周径 4か所」（体重などの後に、腕、脚の順で並べる）
- 行を押すと記録画面が編集の状態で開き、値を見て修正・削除できる。

### グラフ（履歴）

- グラフの種類の選択肢に「周径」を1つ足す。選ぶと、次のものが出る。
  - 「腕｜脚」の切り替え（記録画面と同じく、前回使ったほうを覚える）
  - その下に5部位のボタン（手のひら・手首…）
  - グラフの範囲（期間）の選び方は、今のグラフと同じにする。
- 選んだ部位について、左と右の2本の線を描く。
  - 今のグラフと同じく、記録した点をすべて描く。横軸は記録時刻にする。
  - 左右の色は固定する。左右の区別が、色だけに頼らない形にする（凡例の「左」「右」の文字と、点の形の違いなど。方法は作る人に任せる）。
  - 片側しか測っていない記録は、その側の点だけを描く。
- 点に触れたときの吹き出しには、次を出す。
  - 日時（例「10/20 07:10」）
  - その側の値と、前回との差（例「右 24.5cm（前回 +0.3）」）
  - 同じ記録に反対側の値があれば、その値と左右差（例「左 22.4cm　左右差 2.1」）
- 同じ記録の左右の点は同じ時刻に並ぶ。触れたときは2つの吹き出しを出さず、1つの吹き出しに両側の情報をまとめる。
- 「前回」は、その点より前の記録のうち、同じ部位・同じ側の値を含む一番新しいものとする。グラフの範囲より前の記録も含める。前回がなければ差は出さない。
- 左右差は「右−左」ではなく、差の大きさ（絶対値）と、どちらが大きいかで表す（例「左右差 2.1（右が大きい）」）。左右差は、**同じ記録の中に左右がそろっているときだけ**出す。別々の記録の値を組み合わせない。
- 差の符号は、増えたら「+」、減ったら「−」。0 なら「±0.0」とする。

### 同期と書き出し

- 20件の項目は、今の仕組みのまま、スプレッドシートの体の数値のタブと CSV の列に足す。
  - 今の同期は、見出しの名前で列を対応させるので、既存の値は消えない。
- 列の名前（項目の id）は、英語のキャメルケースで「部位＋位置＋側」とする（例 `armForearmRight`）。
  - 一度決めたら変えない。具体的な名前は作る人が決める。
- CSV の見出しの表示名の扱いは、今の項目と同じにする。

### 言語

- 部位の名前、ヘルプの文、グラフの文言は、ja と en の両方に足す。

## 作る人に任せること

- 項目一覧の型の広げ方（部位・位置・側の持たせ方）と、i18n キーの命名
- 記録画面の部品の分け方（今の `MeasurementForm` を広げるか、周径の部品を分けるか）
- 「前回使った腕／脚」の保存方法（今の「前回使った種類」と同じ方法でよい）
- グラフの部品の作り（今の Recharts のグラフを広げるか、周径用に分けるか）
- 左右を色以外でも区別する方法
- ヘルプの図の描き方
- テスト。少なくとも次は自動テストにする。
  - 記録画面で「腕｜脚」を切り替えても、入力が消えず、保存すると両方が1件に入ること
  - 入力しなかった欄が保存されないこと
  - 吹き出しの「前回との差」が、同じ部位・同じ側の一つ前の記録から計算されること（グラフの範囲より前の記録も含む）
  - 左右差が、同じ記録に左右がそろっているときだけ出ること
  - 周径の項目が、同期の列と CSV の列に出ること
