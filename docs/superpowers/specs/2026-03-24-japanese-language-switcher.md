# 日本語デフォルトの言語切り替え仕様

## 概要

ExerLog は日本人利用者を主対象としているため、アプリの初期表示言語を日本語に変更し、必要な利用者だけが英語へ切り替えられるようにする。

今回の対象は **固定 UI 文言の多言語化** に限定する。運動タイトルや説明文のような外部由来コンテンツは、将来的な YouTube 等からのインポートを想定し、取り込んだ元の言語をそのまま表示する。

## 目的

- 日本語話者が初回利用時から迷わず操作できるようにする
- 英語利用者にも最低限の切り替え手段を提供する
- 今後の外部コンテンツ取り込みを妨げない形で多言語対応の土台を作る

## 決定事項

### 1. 言語の既定値と保存

- 既定値は `ja`
- 利用者が言語を切り替えたら端末内に保存する
- 次回以降は保存済み言語を優先して表示する
- 保存先は既存のローカルファースト方針に合わせて `localStorage` を使う

### 2. 切り替え UI

- 言語切り替えは画面上部ヘッダーに常設する
- ラベルは利用者に分かりやすい `日本語 / English` とする
- 切り替えはアプリ全体に即時反映する

### 3. 翻訳対象

翻訳対象に含めるもの:

- ナビゲーション文言
- ページ見出し
- 固定 UI に属する補助説明文や案内文
- ボタン文言
- フォームラベル
- プレースホルダー
- 空状態やローディング文言
- 履歴画面などで使う日付表示書式
- アクセシビリティのための `aria-label` など固定 UI に属する補助文言

翻訳対象に含めないもの:

- 運動タイトル
- 運動説明文
- 将来 YouTube 等から取り込む外部コンテンツ文言
- 既存保存データの内容そのもの

補足:

- 「説明文」を翻訳対象に含めるのは、ボタンの近くにある案内やフォーム補助テキストなど **固定 UI 文言** のみとする
- 画面内に表示されていても、運動データや外部コンテンツ由来の本文は翻訳対象に含めない

### 4. 外部コンテンツの扱い

- 外部コンテンツは元言語を尊重してそのまま表示する
- UI 言語の切り替えは、コンテンツ本文の翻訳機能を意味しない
- 将来コンテンツ側に `ja` / `en` の両方が揃った場合でも、今回の実装ではそこまで扱わない

## 推奨実装方針

### アーキテクチャ

- ルート近くに `LanguageProvider` を置く
- `useLanguage()` もしくは `useTranslation()` で現在言語と辞書参照を行う
- 辞書は `ja` と `en` を分けた静的オブジェクトで管理する
- 既存コンポーネント内の直書き文言を段階的に辞書参照へ置き換える
- 保存済み言語が存在しない、または `ja` / `en` 以外の値であれば `ja` にフォールバックする

### 想定ファイル構成

- `src\features\i18n\language-provider.tsx`
- `src\features\i18n\use-translation.ts`
- `src\features\i18n\messages\ja.ts`
- `src\features\i18n\messages\en.ts`
- `src\components\app-shell\language-switcher.tsx`

必要に応じて既存の画面コンポーネントから固定文言を移行する。

### 日付表示

- 現在は英語ロケール前提の `Intl.DateTimeFormat("en-US")` があるため、選択言語に応じてロケールを切り替える
- 例: 日本語は `ja-JP`、英語は `en-US`

## 画面別の変更イメージ

### 共通レイアウト

- `html lang` は有効言語と整合する値に更新する
- 少なくともクライアント表示上のヘッダーとナビは選択言語で統一する
- 保存済み言語の読み出し後に文言が別言語へ切り替わるちらつきは避ける
- 必要なら言語初期化完了まで固定 UI の描画を待つ軽量な初期化処理を許容する

### Today

- 見出し、説明文、体調入力、保存ボタン、ローディング文言を翻訳対象にする

### Library

- フィルター名、検索プレースホルダー、補助文言など固定 UI を翻訳対象にする
- 運動タイトルや説明は元データの言語を維持する

### History

- カレンダー周辺の固定ラベル、状態文言、日付表示を翻訳対象にする

### Exercise detail

- 固定ボタンや補助文言のみ翻訳対象にする
- 運動タイトルと説明は元データの言語を維持する

## 非対象

- URL を `/ja` `/en` に分けるルーティング対応
- 自動翻訳
- 外部コンテンツの言語推定
- サーバー保存やアカウント同期

## 実装時の注意点

- 初回描画では hydration mismatch や日本語→英語への後追い切り替えを避ける
- テストは既存の文言依存テストが多そうなので、辞書参照に合わせて更新する
- 文字列の直書きを増やさず、新規固定文言は辞書に集約する
- 外部コンテンツの型は無理に多言語化せず、固定 UI と混ぜない

## 受け入れ条件

- 初回表示は日本語になる
- 保存値がない場合、または保存値が不正な場合は日本語で表示される
- 言語切り替え UI は全主要画面で上部ヘッダーに常時表示される
- モバイル幅でも別メニューに隠さず直接操作できる
- ヘッダーから日本語と英語を切り替えられる
- 切り替え結果がアプリ全体の固定 UI に反映される
- 切り替えた言語は次回アクセス時も保持される
- 運動タイトルと説明は切り替え対象にならず、元データの言語のまま表示される
- 日本語表示では `ja-JP`、英語表示では `en-US` 相当の `Intl.DateTimeFormat` を用いた日付表示になる
- 有効言語に応じて `html lang` が整合する
