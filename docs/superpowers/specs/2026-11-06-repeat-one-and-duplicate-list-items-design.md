# 1本くり返しボタンと、同じ動画を何回も入れられるマイリスト 設計

日付: 2026-11-06
前提: `2026-11-05-continuous-play-in-player-design.md`（プレイヤー画面の連続再生。main にマージ済み）

## 意図と背景

ユーザーは、同じ運動を何回かやりたいことがある。回数は前もって決めているが、調子がよければその場で増やすこともある。

- **決まった回数**: マイリストに同じ動画を何回も入れて表す。並べ方は**間をあけて**（スクワット → ストレッチ → スクワット → ストレッチ）。続けて「×3」と数を付ける形ではない。
- **その場で増やす分**: プレイヤー画面の「この動画をくり返す」ボタンで足す。

## ゴール

### A. 1本くり返しボタン（🔂）

- プレイヤー画面の動画の下に置く。連続再生オンのときは ⏮ ⏭ の横。
- 連続再生オフで 1 本だけ見ているときも出す。
- オンの間は、今の動画が最後まで流れるたびに、頭（区間指定があればその開始位置）からもう一度流れる。
- オフにしても、今流れている動画は止めない。終わったときの動きが普段どおりに戻るだけ。
  - 連続再生オンなら次の動画へ進む。最後の動画でループがオフなら止まる。
  - 連続再生オフなら止まる。
- 自動できた（`playlist_auto_check`）がオンで連続再生もオンなら、最後まで流れるたびに 1 件ずつ記録する。ループで 2 周したときと同じ扱い。同じ再生の中で手で記録した回は、今までどおり自動の記録を足さない（再生 1 回ごとに判断する）。
- ⏭・⏮・「次に流れる」のタップで別の動画に移ったら、くり返しはオフに戻る。このボタンは「今のこの動画」に対するもの（**私の判断**）。
- 前回の設定は覚えない。画面を開くたびにオフから始まる（**私の判断**）。その日の調子で押すものなので。
- 区間指定（`start`/`end` 付き）の動画: 今は 1 本だけ見るとき自動でくり返している。この動きを変えないため、**連続再生オフで**その動画を再生し始めたときは、くり返しが最初からオンの状態にする。止めたいときはボタンでオフにする（ユーザー了承済み）。
  - 連続再生オンのときは自動でオンにしない。区間指定の動画も今どおり 1 回流れたら次へ進む。くり返したければ 🔂 を押す（ユーザー決定）。
  - 今の `use-playlist.ts` の「連続再生オフで区間指定ならくり返す」処理は、このくり返しフラグに置き換える。
  - 再生中に連続再生のオン・オフを切り替えても、くり返しの状態はそのまま（**私の判断**）。

### B. 同じ動画を何回も入れられるマイリスト

- 保存形式はもともと並び（`ExerciseSet.exerciseIds: string[]`）なので、形式の変更はいらない。同期（スプレッドシートの JSON 配列）もそのまま。
- 今は表示側（`resolveSetExercises` の `new Set`）や追加メニューのチェックで、同じ動画を 1 つにまとめている。これをやめ、並びの中の重複をそのまま扱う。
- **追加**: 動画カードの ⋮ メニュー（`ExerciseSetMenu`）で、その動画がもう入っているリストの横に「＋」を出す。押すと同じ動画をもう 1 つ、リストの**最後**に足す。メニューは閉じない（今のチェックと同じ）。
- **並べ替え**: ライブラリの編集モードにある今のドラッグをそのまま使う。重複があっても 1 枚ずつ動かせること。
- **1 枚だけ外す**: リストを開いた状態のカードの ⋮ から「このリストから外す」。そのカード（並びの中のその位置）1 枚だけを外す。
  - ライブラリと今日の画面の、マイリストを選んでいるときのカードの両方に出す。ライブラリの並べ替え（下書き）中は出さない（**私の判断**）。
  - プレイヤー画面の「+ リスト」ボタンは今のまま。「＋」も「外す」も足さない（**私の判断**）。
- ⋮ メニューのチェックを外したときは、今までどおりそのリストから全部外す（**私の判断**）。
- **表示**: 今日の画面・ライブラリでマイリストを選んでいるときは、入れた数だけ同じ動画のカードが並ぶ。
  - 「今日◯回」の数は、どのカードも同じ動画の合計。
  - どのカードの「できた」を押しても、その動画に同じように記録される。
- 「すべて」と今日のおすすめ 3 本は今のまま。同じ動画は 1 枚だけ。
- **連続再生**: リストに見えている並びのとおりに流れる。2 枚目のスクワットのカードを押して開いたら、**その位置から**始まる（1 枚目の位置に戻らない）。
- **シャッフル**（ライブラリの並び「シャッフル」と、プレイヤーのシャッフル）: カード 1 枚ずつを別々の位置として混ぜる。同じ動画がたまたま隣り合ってもよい（ユーザー決定）。
  - 混ぜても入れた数は減らない・増えない。シャッフルを切ったら元の並び（重複の位置も含め）に戻る。
  - 今のシャッフルは並びを動画 id の列として保存・適用している（`shuffleIds`, `applyOrder`, `LibraryShuffle.order`, `PlayQueue` の `unshuffledIds`/`listIds`、プレイヤーの id による位置合わせ）。重複があると id では位置が決まらないので、位置で扱えるように直す必要がある。

## ノンゴール

- 「×3」のような回数指定。
- 「すべて」の一覧に同じ動画を 2 回出すこと。
- くり返し回数を指定する機能（「あと 2 回」など）。くり返しはオン・オフだけ。

## やってはいけないこと（技術的には動いても失敗）

- 重複を入れたら、並べ替え・外す操作で別の位置のカードが動いたり消えたりする。
- 2 枚目のカードから開いたのに、連続再生が 1 枚目の位置から始まる。
- くり返しをオフにした瞬間に今の動画が止まる・次へ飛ぶ。
- くり返しで 2 回流れたのに、自動の記録が 1 件しか付かない／手の記録と二重に付く。
- 連続再生オフの画面が、くり返しボタンの追加以外で変わる。

## 作る人に任せること

- 🔂 ボタンの見た目。今の ⏮ ⏭（`.player-screen__skip`）と同じ大きさ・トーンで、オン・オフが離れて見ても分かること（`aria-pressed`）。
- カードの「位置」をプレイヤーへ渡す方法。今は `sessionStorage` の `exerciseIds` だけを渡している。押したカードの位置を一緒に記録するなど。分からなければ、最初に出てくる位置から始める。
- React の `key` や並べ替え用の id が `exercise.id` になっている所（`reorder-list.tsx`, `library-screen.tsx`, `today-screen.tsx`）は、位置を含むものに変える必要がある。
- `setExerciseInSet` の外す処理（今は全部外す）とは別に、位置で 1 つだけ外す処理を足す。
- 「＋」の文言とアクセシブルな名前。ja/en の両方。

## レビューで出た問い（解決済み）

1. 連続再生中の区間指定の動画でくり返しを自動オンにするか → しない（A の該当箇所）。
2. 重複のあるリストのシャッフル → カード 1 枚ずつ混ぜる（B の該当箇所）。
3. 「外す」「＋」をどこに出すか → 私の判断で決めた（B の該当箇所）。
