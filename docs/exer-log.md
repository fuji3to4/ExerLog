運動・コンディション記録アプリ 要件定義（案）

※フィットネス用途を基本とし、医療・研究への将来的展開も見据えた設計

# 1 開発の背景と目的

運動やセルフケアの継続は、健康維持や生活の質（QOL）の向上において重要である一方、

- 「何をすればよいか分からない」
- 「正しくできているか不安」
- 「続いているかを振り返れない」

といった理由から、習慣化が難しいという課題がある。

本アプリは、

**動画による運動提示・簡単な実施記録・振り返り（可視化）**を一体化することで、

専門的な知識を前提とせず、誰でも無理なく運動やセルフケアを継続できる環境を提供することを目的とする。

本要件では、特定の疾患名や診断行為を前提とせず、

**一般的なフィットネス・コンディション管理アプリ**として設計する。

# 2 想定利用者

- 一般利用者（患者・クライアント）
  - スマートフォン操作に慣れていない人も含む
- コンテンツ提供者
  - 医師、看護師、理学療法士、作業療法士・トレーナー・インストラクターなど
  - 指導用コンテンツの補助、セルフケア状況の把握を想定

# 3 基本コンセプト

**「見る → 行う → 振り返る → 次につなげる」**

- **動画で運動内容を確認**
- **実施したら簡単に記録**
- **カレンダーやグラフで振り返り**
- **その人の状況に合った運動を提案**

医療行為や診断を行うものではなく、

**日常的な運動・セルフケアの"記録と気づき"を支援するツール**と位置づける。

# 4 主な機能要件

## 4.1 動画コンテンツ機能

- 運動・ストレッチ・リカバリー等の動画を一覧で表示
- 動画は以下の観点で分類
  - 対象部位（上半身／下半身／全身 など）
  - 目的（筋力向上／可動域／リラックス など）
  - 所要時間（5分、10分など）
  - 強度（軽い／普通／やや強い）
- YouTube 等の動画配信サービスを活用（運用・更新の負担軽減）

## 4.2 運動実施の記録

- 「実施した」ボタンを押すだけで記録可能
- 記録内容（最小限）
  - 実施日
  - 実施した運動（動画）
  - 実施状況（できた／一部／できなかった）
- 任意で簡単なメモ（疲れた、軽かった など）

※入力負担を最小限にすることを最優先とする。

## 4.3コンディションの簡易記録（任意）

- 日々の体調を簡単に入力
  - 元気／普通／疲れ気味 などの選択式
- 痛みや張り感などを自由記述で補足可能

※数値評価や診断的表現は行わない。

## 4.4カレンダーによる振り返り

- 月・週単位で運動実施状況を確認
- 実施した日はカレンダー上に印を表示
- 日付を選ぶと、その日の運動内容を一覧表示
- Googleカレンダーと連携？

→**「いつ・どれくらいできているか」が直感的に分かる**

# 5 開発・運用方針

- 初期段階では **Webアプリ（PWA）** として提供
  - PWA（Progressive Web Apps）とは、Webサイトをスマートフォンのネイティブアプリのように使えるようにする技術
  - **Webの利便性（ストア不要、クロスプラットフォーム）とアプリの機能（ホーム画面アイコン、オフライン利用、プッシュ通知、高速表示）を両立**させます。
- データの保存：
  - 利用者の端末内にIndexedDBベースで記録を保存し、運用コストを抑制。**スマホ・PC間などの連携はできない**。
  - 拡張機能との関連だが、外部さービスGoogleカレンダー等で運動記録等も含めて記録できるなら、その方が便利かも
  - 将来的には段階的にサーバーによる一律管理も検討
    - ログイン機能を持たせ、個々のデータをサーバーで管理する。これにより同一ユーザーですべてのデータを一元管理が可能
    - 医師・患者間のデータの共有もサーバー経由で可能
    - ただし、サーバー運営のコストがかかる

# 6 拡張機能（優先順位順に）

## 6.1 運動動画コンテンツの追加・管理機能

- 運動動画コンテンツ向けの簡易管理画面を提供し、Y**ouTube 等の動画配信サービスのリンクを登録**可能とする。
- 登録時に、以下の情報を付与できる。
  - 動画タイトルおよび簡単な説明文
  - 対象部位（上肢、下肢、体幹、全身など）
  - 目的（筋力向上、可動域改善、リラクゼーション等）
  - 運動強度（軽い、普通、やや強い）
  - 所要時間（目安）
- 追加された動画は、一般利用者向けの動画一覧や「おすすめ運動」に反映される。
- Googleスプレッドシートに動画URL・タグ・所要時間等を表で管理
- アプリはそれを読み込んで表示（公開範囲は工夫する）

## 6.2 外部サービスとの連携

- Googleカレンダーとの連携
  - 運動記録を個人のカレンダーに反映
  - 他の予定と一緒に振り返りが可能

## 6.3おすすめ運動の提示（軽いレコメンド）

- これまでの実施状況や当日の体調に基づき、
  - 「今日は短時間の運動」
  - 「最近行っていない部位の運動

などを提案

- 推薦理由は短い文章で表示

※高度なAI診断ではなく、**あくまで運動継続を助けるための補助的提案**とする。

## 6.4 3Dスキャンによる身体計測

- スマートフォンの3Dスキャンアプリ等で取得したデータを活用
- 腕や脚の体積・周囲長の推移を算出・記録
- 数値はあくまで「変化の記録」として提示

※診断や病状判定は行わない。

# 7 非機能要件（運用・倫理配慮）

- 医療行為・診断を行わない（フィットネス・運動管理として開発）
- 疾患名や重症度判定を表示しない
- 数値や変化については「参考情報」として提示
- 利用者が不安を感じた場合は、「必要に応じて専門家に相談してください」といった一般的注意喚起に留める

# 8 本アプリの位置づけ

本アプリは

- 診断・治療・評価を目的とするものではない
- 医療行為の代替ではない

一方で、

- 日常の運動・セルフケアの記録
- 利用者自身の「気づき」
- 医療・リハビリ職とのコミュニケーション補助

として活用されることを想定する。
